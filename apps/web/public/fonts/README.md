# Credence typography

These are the same typeface families observed on the user-supplied Vestra reference.
Font binaries are unmodified and self-hosted, so page rendering and production
builds do not depend on a third-party font request.

- Satoshi Variable (300–900): Indian Type Foundry / Fontshare.
  Source: https://api.fontshare.com/v2/css?f[]=satoshi@1&display=swap
  License: ITF Free Font License, https://www.fontshare.com/licenses/itf-ffl
- JetBrains Mono Regular: JetBrains.
  Source: https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts
  License: SIL Open Font License 1.1; included in `JetBrainsMono-OFL.txt`.

Do not assume the application's license also licenses these typefaces.
